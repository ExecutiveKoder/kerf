Personal use

Free after you accept the Kerf Personal Use License. No commercial use. No redistribution — including commercial redistribution.

1

Install with Docker

First run builds the image and installs Python. Later runs just start.

git clone https://github.com/ExecutiveKoder/kerf.git
cd kerf
docker compose up -d
2

Accept the license

Open http://127.0.0.1:8000. Read the terms and check the box. You are accepting personal, non-commercial use only, and agreeing not to redistribute Kerf.

3

Trust the CA on a machine you control

In Setup, download the Kerf CA and install it in that browser or OS trust store. This is how HTTPS interception works. Remove the CA when you are done.

4

Point a browser at the proxy

HTTP/HTTPS proxy: 127.0.0.1:8080. Browse in-scope hosts. Traffic lands in History. Repo scans are under Scan → Repos.

Without Docker: pip install -r requirements.txt && python main.py. History, the CA, and the license acceptance live in ./data (Docker) or ~/.dastday.

Run Kerf only against systems you own or have explicit written permission to test. Intercepting other people’s traffic is illegal in most jurisdictions.

What ships

One process on your machine. SQLite history. No hosted cluster.

Proxy toolkit

  • HTTP/1.1, HTTP/2, WebSockets, local CA
  • History, intercept, Replay, rewrite, cookies
  • Encode, Compare, Tokens, reports

Authorized scanning

  • Passive findings on captured traffic
  • GitHub repo SCA / secrets / dangerous APIs
  • Scan engine without a public exploit catalog
