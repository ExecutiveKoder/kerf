Kerf
GitHub

A local proxy for your own web apps.

History, replay, and a browser already on the proxy. It stays on your machine. Personal use.

git clone https://github.com/ExecutiveKoder/kerf.git
cd kerf
docker compose up -d

Open 127.0.0.1:8000 and accept the personal-use license. Data lives in ./data, or in ~/.kerf if you start it with Python instead of Docker.

Only test systems you own or have written permission to test.
