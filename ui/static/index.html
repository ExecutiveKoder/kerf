Setup

        
Certificates, AI, outbound hop, and the personal-use attestation.

      

      

        

          
          
          
          
          
        


        

          
    
            
  1. Open the Kerf browser. 
              
    
              Isolated Chromium, already using 127.0.0.1:8080.
    2. 
            
  2. Download the CA if you want HTTPS to validate in a browser you configure yourself.
              
              The Kerf browser already ignores the intercept cert, so this is optional there.
    3. 
            
  3. Trust it in that browser or OS trust store. The CA only affects clients that install it — your own machine.
    4. 
            
  4. Turn Intercept on when you want to hold a request, then browse in the Kerf window.
    5. 
          

          

            Intercept and scan only on systems you own or are authorized to test. The CA cannot intercept anyone else's traffic.

Outbound proxy

            
After Kerf intercepts a request, send it out through Tor or another proxy. Direct is the default. Start Tor yourself — Kerf does not bundle it.

            
DIRECT
              No outbound hop. Traffic leaves this machine normally.

            
            
            

              

                
                
              

              

                
              

            

            

              

              

            

            

              

              

            

            

              
              
              
            

            

              Tor: install and start the Tor service, or open Tor Browser, then pick the matching preset and Save.
              Replay, Payloads, and Scan use this hop too. Only use it on systems you are authorized to test.
