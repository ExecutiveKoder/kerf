Setup

        
Certificates, AI, and an optional outbound hop (Tor or another proxy). Only on a machine you control.

      

      

        

          
          
          
        


        

          
    
            
  1. Open the SureGuard browser. 
              
    
              Isolated Chromium, already using 127.0.0.1:8080.
    2. 
            
  2. Download the CA if you want HTTPS to validate in a browser you configure yourself.
              
              The SureGuard browser already ignores the intercept cert, so this is optional there.
    3. 
            
  3. Trust it in that browser or OS trust store. The CA only affects clients that install it — your own machine.
    4. 
            
  4. Turn Intercept on when you want to hold a request, then browse in the SureGuard window.
    5. 
          

          

            Intercept and scan only on systems you own or are authorized to test. The CA cannot intercept anyone else's traffic.

Outbound proxy

            
After SureGuard intercepts a request, send it out through Tor or another proxy. Direct is the default. Start Tor yourself — SureGuard does not bundle it.
