Active scan

        
The engine that drives operator-supplied active checks against an authorized scope.

      

      

        

          No active checks are loaded. This build ships the active-scan engine without any
          attack payloads. Active scanning sends crafted requests to probe for vulnerabilities, which
          behaves the same against a system you own and one you do not, so the checks are left to you to
          supply for targets you are authorized to test.
        

        

          To enable it: write an ActiveCheck, drop it in extensions/, and
          assert an authorized scope with authorize_scope({...}). The engine refuses to run
          on an empty scope. See docs/WRITING_ACTIVE_CHECKS.md.
